# L-003: T. Tao, "Equidistribution of Syracuse random variables and density of Collatz preimages"

Blog post, terrytao.wordpress.com/2020/01/25/. Fetched and read 2026-07-22.

## Verified definitions

Syracuse random variable:

```
Syrac(Z/3^n Z) := sum_{m=1}^{n} 3^{n-m} 2^{-(a_m + a_{m+1} + ... + a_n)}   (mod 3^n)
```

where a_1,...,a_n are i.i.d. copies of Geom(2) on the positive integers,
P(a_1=a_1,...,a_n=a_n) = 2^{-(a_1+...+a_n)}. Arithmetic mod 3^n; `2^{-k}` means the inverse
of `2^k` mod 3^n (well-defined since gcd(2,3)=1).

```
c_n := inf{ P(Syrac(Z/3^n Z) = b) : b in Z/3^n Z, 3 does not divide b }
```

examples given: c_0=1, c_1=1/3, c_2=2/63.

**Conjecture beta=1**: c_n = 3^{-n+o(n)} as n -> infinity. Implies (conditionally, proven in
the same post) Collatz preimage density >> x^{1-o(1)} (almost total).

## Object-identity check (done independently, 2026-07-22, before consulting advisor)

Re-derived the "unit twist" claim of the previous paper's Proposition (beta-wcc) myself, to
check it rather than take it on faith (Rule 11). Reindexing Tao's sum with i := n-m gives
`Syrac = sum_{i=0}^{n-1} 3^i * 2^{-b_i}` where `b_i := a_{n-i}+...+a_n`, and since each a_j >= 1,
the b_i are strictly increasing positive integers (0 < b_0 < b_1 < ... < b_{n-1}). Multiplying
by the unit `2^{b_{n-1}}` (does not change which residue class mod 3^n is hit, only relabels it)
gives `sum_i 3^i * 2^{g_i}` with `g_i := b_{n-1} - b_i`, which is strictly DEcreasing in i and
bounded below by 0 (g_{n-1}=0). This is exactly Wirsching's R_{j,k} shape (decreasing exponents
of 2, bounded below by 0), confirming the object-identity claim: Tao's Syracuse variable and
Wirsching's R_{j,k} sums are literally the same combinatorial object up to a unit multiple
(relabeling which residue class is "hit"), matching what the previous paper's Proposition
(titled "Structural identity") and the researcher's brief both assert. This part checks out.

## What is NOT a full equivalence (and the paper does not claim it is)

The previous paper's Proposition states WCC (Conjecture 3.9) implies beta=1 cleanly (an exact
entropy count), but that beta=1 alone gives only an "exponentially weakened form" of WCC back;
this is an explicit, correctly-flagged asymmetry in the paper, not an oversight. The reason: WCC
is a SET-COVERING statement (every residue is hit by at least one element of R_{j,k}); beta=1 is
a PROBABILITY LOWER BOUND statement (every residue has probability >= 3^{-n+o(n)} under the
specific non-uniform measure induced by the geometric weights). Set-covering is a stronger,
purely combinatorial condition; the probability bound is weaker and analytic. The two share the
same underlying object (confirmed above) and the same entropy scale (log_4 3), but "same object"
does not by itself hand you "same strength of conclusion" in both directions.

## What H-002 should actually verify (narrowed after advisor consultation)

Not "the equivalence" (there is no claimed bidirectional equivalence to check: the paper is
explicit that only WCC => beta=1 is claimed cleanly). The one non-mechanical step worth
independently re-deriving is the entropy-count bridge: `j = log_4(3)*l + o(l)` (from a covering
family existing at that size) implies `c_l >~ 3^{-l(1+o(1))}` (a probability lower bound). The
object-identity itself (this note, above) is mechanical and now independently confirmed twice
(paper + my own rederivation); the bridge is where an error could actually hide, since it is
where a counting statement gets converted into an infimum-of-probability statement.
