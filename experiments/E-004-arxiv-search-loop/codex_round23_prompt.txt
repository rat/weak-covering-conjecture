## CONTEXT: the open problem

Wirsching's Weak Covering Conjecture (1998, Springer LNM 1681, Conjecture 3.9). Define
  R_{j,k} := { sum_{i=0}^{j} 2^{a_i} 3^i : j+k >= a_0 > a_1 > ... > a_j >= 0 }  (subset of Z_3^*).
Let j*(l) = smallest j such that R_{j-1,j} covers (Z/3^l Z)^* mod 3^l. Exact values are known by
computation for l = 1..23. Define the "excess"
  e(l) := j*(l) - l*log_4(3).
The counting/entropy threshold is l*log_4(3) because |R_{j-1,j}| = C(2j-1,j) ~ 4^j/sqrt(pi j) and
covering needs >= 2*3^{l-1} values. Known rigorously: e(l) >= (1/4)log_2(l) - O(1) (elementary
pigeonhole with the Stirling correction), so e(l) is unbounded. Best proven upper bound:
j*(l) <= (5/3) l + O(1) (an exactly-solved mean-payoff-game cylinder relaxation, value rho_4 = 5/3;
rho_k continues 3/2, 3/2, 7/5, 25/19, 5/4, 11/9, 6/5 for k = 6..11).

THE ACTUAL OPEN QUESTION is the GROWTH RATE of e(l): is it Theta(log l), Theta(sqrt l), or a slow
linear term? Empirically e(l) grows (l=1..23; dAIC = 16.09 against a plateau model). An elementary
explicit bound on j*(l) itself does NOT answer this.

## THE STRUCTURAL OBSTRUCTION (22 prior rounds all reduced to exactly this)

Reduced computational form: choose an l-subset S of {0,...,l+j-1}, sort decreasing s_1 > ... > s_l,
value = sum_{i=1}^{l} 2^{s_i} 3^{i-1}. The weight 3^{i-1} attaches to the RANK i of s_i within the
chosen set, not to s_i itself. Change which other elements are chosen and the same s moves rank and
picks up a different power of 3. Every framework tried (Bajnok sumsets, Combinatorial
Nullstellensatz, Li-Wan character sums, 3-adic transfer operators, noncommutative transfer
matrices, quasisymmetric functions, coupon-collector/Erdos-Turan discrepancy) provably reduces to
bounding the same exponential sum
  S(t) = sum over admissible tuples of exp(2*pi*i*t*value/3^l),
for which no bound is known. Transfer operators were PROVED to diagonalize to exactly S(t);
the noncommutative transfer matrix coefficient literally IS S(t).

## WHAT I FOUND TODAY (please attack this)

**Finding 1 (object-level).** Tao's Syracuse random variable (Forum Math. Pi 10 (2022) e12,
Definition 1.7 / eq. 1.21):
  Syrac(Z/3^n Z) = sum_{m=1}^{n} 3^{m-1} 2^{-a_[1,m]},  a_j iid Geom(2), P(a_j=k)=2^{-k}, k>=1,
is the SAME rank-coupled object. I verified computationally (exact set equality, l=2..4, several j,
including this project's ground-truth checkpoint R_{1,2} mod 9 = {1,2,5,7}) that both
R_{l-1,j} mod 3^l and Syrac are unit multiples of one common core sum
  G(a_2,...,a_l) = sum_{i=1}^{l} 3^{i-1} 2^{-(a_2+...+a_i)},   a_j >= 1,
namely: our value = 2^{s_l + B} * G with B = sum_{m=2}^{l} a_m, and Syrac = 2^{-a_1} * G. The two
differ ONLY in the measure on gap tuples: ours is uniform over tuples with a budget constraint
(s_l + B <= l+j-1), Tao's is the product-geometric measure with no budget cap.

**Finding 2 (an existing rigorous bound on exactly this sum, which 22 rounds never cited).**
Tao's Proposition 1.17 states: for xi in Z/3^n Z with 3 not dividing xi, and any fixed A > 0,
  | E exp(-2*pi*i*xi*Syrac(Z/3^n Z)/3^n) | << _A n^{-A}
i.e. super-polynomial decay, proved via his Lemma 1.12 recursion
Syrac_{n+1} = 2^{-a}(3 Syrac_n + 1). That recursion is exactly a device that converts the
rank-coupling into recursion depth. So a nontrivial rigorous bound on this rank-coupled exponential
sum DOES exist in the literature.

**Finding 3 (an exact convex-combination bridge, verified numerically to 1e-10).**
Write psi_n(xi) = E exp(-2 pi i xi Syrac/3^n). Grouping gap tuples by total budget B and writing
L_{B,u}(xi) = sum over gap tuples with total B of exp(-2 pi i xi 2^u G / 3^n), I verified exactly
(n=3,4,5, at the extremal frequency) that
  psi_n(xi) = sum_{B,u} w_{B,u} * ( L_{B,u}(xi) / |T_B| ),  |T_B| = C(B-1,n-2),
with weights w_{B,u} = 2^{-B-u} |T_B| summing to exactly 1. The L_{B,u} are, up to a unit twist of
the frequency, exactly this project's fixed-budget S(t). So psi_n is a convex combination of the
NORMALIZED versions of our own S(t).

**Finding 4 (new numerics on exactly this sum).** T. Toguchi, "Numerical observations on extremal

**Finding 5 (the barrier I want you to attack).** Two claims:

(5a) QUANTITATIVE. Square-root cancellation for our S(t) would mean normalized |L_B|/|T_B| <~
|T_B|^{-1/2} ~ 2^{-n} (since the budgets carrying essentially all the geometric weight have
|T_B| ~ C(2n,n) ~ 4^n/sqrt(pi n)). But the layer weights w_B = 2^{-B} C(B-1,n-2) are exactly the
pmf of a sum of n-1 iid Geom(2) (mean 2(n-1)), so by an exact Chernoff/tail computation the layers
outside a window of half-width O(sqrt(n log n)) around 2(n-1) carry total weight < M_n/2, whence
SOME budget B inside that window has normalized |L_B| >= M_n/2. Measured: M_21/2 = 3.9e-3 versus
2^{-21} = 4.8e-7, a factor ~8000, and the gap grows exponentially in n. Conclusion: square-root
cancellation for this rank-coupled sum is FALSE at the budgets that matter, by an exponential
margin (contingent only on Toguchi's numerics, which I reproduced up to n=9).

(5b) STRATEGIC. The L^1 (triangle-inequality / major-arc) Fourier covering criterion needs
sum_{xi != 0} |S(xi)| < T where T = |index set|. With ~3^l frequencies this needs the normalized
extremal coefficient below ~3^{-l}. Even PERFECT square-root cancellation |S| ~ sqrt(T) only yields
T >~ 3^{2l}, i.e. 4^j >~ 3^{2l}, i.e.

Compare: the already-proven elementary mean-payoff-game bound is j*(l) <= (5/3) l = 1.6667 l, and
the conjectured truth is log_4(3)*l = 0.7925 l. So the ENTIRE 22-round program of "bound S(t)",
even if executed perfectly to the square-root barrier, could at best improve the leading constant
from 1.6667 to 1.5850 and provably CANNOT reach the log_4(3)*l scale where e(l) lives. Therefore no
amount of progress on S(t) via the L^1 Fourier route can distinguish log l vs sqrt l vs linear
growth of e(l).
